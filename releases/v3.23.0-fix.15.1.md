### v3.23.0-fix.15.1 — Docker sysctl Hardening

This patch adds recommended kernel network settings to all Docker deployment examples to prevent conntrack table exhaustion under high proxy load.

### Documentation

• **Optimized sysctls in Docker examples**: All `docker-compose.yml` examples now include `nf_conntrack_max=2097152` and `nf_conntrack_tcp_timeout_established=5400` by default. These prevent silent packet drops on busy nodes where the conntrack table fills up with no visible log error.
