### v3.23.0-fix.15.1 — Docker sysctl Hardening

### Documentation

• **Optimized sysctls added to Docker examples**: All `docker-compose.yml` examples now include `nf_conntrack_max=2097152` and `nf_conntrack_tcp_timeout_established=5400` by default. These settings prevent conntrack table exhaustion under high proxy load, which previously caused silent packet drops on busy nodes with no visible error in logs.
