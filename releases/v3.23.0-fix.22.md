**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.22
```

```sh
docker run -d \
  --name=urfix \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
```

## Highlights

### 🛡️ Security Hardening (QUIC)
Bumped `quic-go` to `v0.59.1`. This resolves a memory exhaustion vulnerability where an unauthenticated remote attacker could cause the provider to allocate excessive memory during the handshake. All operators using QUIC-based transports (H3) are encouraged to update immediately.

### 📊 Expanded RAMLOGS & Log Management
The in-memory diagnostic buffer has been significantly expanded to support high-volume nodes.
- **5MB Capacity:** Increased the `RAMLOGS` size from 1MB to 5MB, providing a 5x larger window for retrospective triage without hitting disk I/O limits.
- **Advanced Log Triage:** The `urnet-tools logs` command now supports targeted extraction:
    - `urnet-tools logs all`: Streams the entire 5MB buffer from the beginning.
    - `urnet-tools logs dump`: Captures the current log state to `~/urlogs.txt` for fast attachment to support threads.

### 🐳 Production-Ready Docker Patterns
Added a "Production-Ready" section to the `README` with copy-pasteable examples of best-practice deployment flags:
- **`PROFILE=auto`**: Automatically scales internal buffers and GC limits based on available container RAM.
- **`URNETWORK_RAMLOGS=1`**: Enables high-performance in-memory logging (tail with `docker exec <name> logs`).
- **Persistence**: Explicit volume mounting for `vnstat` bandwidth history and `JWT` configuration to prevent re-authentication on container recreation.
- **CLI Parity**: The `urnet-tools` command is now available inside the container. Operators can use the exact same commands as bare-metal installs (e.g., `docker exec -it <name> urnet-tools proxy health`).
