📦 **Release Notes: v3.23.0-fix.18**

Release Date: June 7, 2026

> [!TIP]
> **Accountability Check:** The new Unified Telemetry system provides 100% wire-transparency. You can now compare the "TOTAL" column (raw wire bytes) against the "BILLABLE" column to calculate the exact protocol overhead (H1/H3 heartbeats vs NAT payload) for every proxy in your fleet.

🛡️ **Self-Healing & Resilience (New in .18)**

**JWT Smart Refresh:** The provider now independently validates its own identity. By parsing the JWT locally to check the exp claim, nodes can detect expiration before making any network calls.

**Exit Code 78 & API Protection:** A new specialized signal for "Definite Auth Failure." This allows the container to exit and trigger a clean re-authentication, preventing generic restart loops from hammering the API with an expired token. This is a critical stability measure that protects your account from being rate-limited or flagged during automated scale-outs or Watchtower updates.

🔄 **Proxy Hot-Reload (Now Built-In)**

Proxies can now be added and removed from a running instance **without a restart**—preserving warm state across your entire fleet.

- `urnet-tools proxy refresh` — Apply your updated proxy config with a diff preview and confirmation prompt
- `urnet-tools proxy remove-dead` — Interactively remove dead (never-authenticated) or inactive (long offline) proxies
- `urnet-tools proxy health` — Stream live proxy status and recovery events
- Stable slot IDs — Re-added proxies automatically restore their original proxy[N] slot number

**Tip:** Triggering a reload that results in an empty proxy list will exit the provider cleanly. This can be used as a controlled shutdown without sending SIGTERM.

📊 **Unified Proxy Telemetry (New in .18)**

**Dialer-Level Tracking:** We've moved the "Accountants" to the absolute bottom of the stack. By tracking at the Dialer layer, we now capture 100% of wire traffic, including internal heartbeats and platform overhead that previously bypassed the NAT counters.

**The clients=0 Fix:** Load metrics now accurately reflect activity even on idle nodes. If a proxy is maintaining a platform connection, it shows up as an active client.

**Session Longevity:** Added age=... to [net][s]select logs and a MAX AGE column to the traffic report to provide deep visibility into connection duration across the fleet.

🔧 **Stability & Fixes (New in .18)**

**Auth Panic Guard:** Replaced brittle panic calls in the authentication path with structured error returns and added nil-guards for API response fields.

**Proxy State Reset:** Fixed a bug where proxy remove --all failed to clear the persistence file.

**CI Modernization:** Full migration to Node.js 24 for GitHub Actions and a new automated unit test suite for the auth/telemetry layers.

> [!WARNING]
> **Configuration Requirement:** To utilize the Self-Healing Auth feature in Docker, you must provide `USER_AUTH` and `PASSWORD` environment variables. Without these, the container will exit on code 78 and wait for manual intervention.
