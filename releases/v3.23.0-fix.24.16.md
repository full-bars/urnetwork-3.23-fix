# v3.23.0-fix.24.16 — 2026-06-25

## What's New

### `proxy clear` now actually clears everything

`proxy remove --all` (called by `urnet-tools proxy clear`) was clearing the internal config and `proxy.state`, but leaving `proxy_url.json` untouched. That file cached every previously-fetched free proxy from prior URL fetches. On restart, all cached URL proxies were reloaded — the clear had no lasting effect.

Now `proxy remove --all` wipes `proxy_url.json` entirely — cache, blacklist, and source URLs. After clear, no URL-sourced proxies will be fetched unless a source is explicitly re-added.

### File-sourced proxies start before URL-sourced ones

The proxy launch order at startup was non-deterministic (Go random map iteration), so file-based and URL-sourced proxies were interleaved — no priority for paid proxies. Now the proxy list is sorted so file-sourced proxies get lower indices in the launch sequence, giving them a head start via `backoffPacer` before any URL-sourced proxies begin connecting.
