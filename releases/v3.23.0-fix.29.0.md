# v3.23.0-fix.29.0 — 2026-08-14

NOTE: Operators must redeploy the provider nodes to get these changes. The hub and the provider binary both change. See section 6.

## 1. Summary

This release makes the fleet dashboard show the A-F grade for each proxy. It reduces the probe traffic for paid proxies. It adds a security check for URL proxy sources. It fixes eight tool errors that the field test found. It closes a resource leak hunt.

## 2. Dashboard Grades

The provider computes an A-F grade for each proxy. The provider did not send these grades to the hub before. Now the provider sends the grade with each report. The report has these fields: score, graded, failed, tier, and last_graded.

The hub stores the grades for each node and proxy. The hub keeps the grades for 7 days. The dashboard shows the grade as a color badge.

The grade column is different from the score column. Do not compare them directly. The provider updates the grade time only when a real grade pass happens. A health check does not update the grade time.

The hub checks the grade value before it stores the value. The hub also escapes the grade text before it shows the text. This closes a stored XSS path.

## 3. Probe Traffic

Paid proxies use a wider stale window. The calm window is 6 hours. The hot window is 3 hours. URL proxies use 3 hours and 1 hour. The paid probe traffic becomes about 3 times smaller.

A paid proxy with a positive billable delta in the last 15 minutes is alive. The provider does not probe it again. The provider measures the delta per address. It does not use the cumulative counter. The provider probes each paid proxy at least once per day. The provider always probes a proxy with no grade.

The provider waits 20 seconds after start. Then it fetches and probes the URL lists. A box that crashes and restarts does not probe the lists again. This stops the probe amplification loop.

## 4. URL Proxy Security Check

The provider tests a URL proxy in three stages. Stage 1 is the SOCKS5 greeting. Stage 2 is the SOCKS5 CONNECT. Stage 3 is new.

In stage 3, the provider makes a TLS handshake through the proxy tunnel. The ServerName field points to the API host. A proxy that shows its own certificate fails the handshake. The provider marks it as probeTLSFailed. The provider never admits it to the pool.

A proxy that was good and later turns hostile fails the reaper check. The reaper counts the failures. The proxy goes to the blacklist. There is no new configuration knob. The check uses the same TLS verification as the provider auth.

## 5. Tools and Other Fixes

The Go tools are release assets now. The tools are urnet-tools and urnet-docker. release.yml builds them for the full platform matrix. The Linux and macOS installers fetch the Go binary and verify the SHA-256 digest. Docker users run install-urnet-docker.sh.

The tool updates itself. urnet-tools update refreshes the provider and the tool. self-update refreshes only the tool. The binary format check works on Linux, macOS, and Windows.

A failed handshake epoch did not retry before. Now restartHandshake rebuilds the failed epoch. The retry uses a 5 second cooldown. The provider frees the parked handshake worker.

The leak hunt closed six confirmed leaks. The fixes are mutation proven. Independent reviewers checked them.

- The source count increments once per bucket and path now.
- The timeout watchdog cancels the epoch context now.
- The client removal cancels the update context now.
- The PQE path uses a sane idle timeout now.
- The control send returns its buffer on cancel now.
- Cancel() unsubscribes the receive callback now.

The field test found eight tool errors. The test ran on a fresh droplet against the beta network. All eight errors are fixed.

- version and --version print the tool version now.
- report writes the report_url file now.
- hot-restart restarts the systemd unit now.
- The systemctl command includes the unit name now.
- summary uses the proxy summary command now.
- add-source and remove-source work now.
- refresh --force sends the force flag now.
- help at any position shows the proxy help now.

The report_url file has mode 0644. A provider that runs as a different user can read the file. hot-restart asks for a typed yes before it restarts. Use -f to skip the prompt.

## 6. Deploy Notes

The dashboard grade column works after the provider nodes update. Until then, the hub shows no grade data for those nodes. The hub does not crash.

The probe cadence changes start after the provider nodes update. The TLS admission check starts after the provider nodes update. The leak fixes start after the provider nodes update.

The Go tools are optional for existing installs. Nothing changes until you run the install script again or run self-update.

If paid probe cadence needs a revert, do a code rollback to fix.28.0. There is no runtime toggle.
