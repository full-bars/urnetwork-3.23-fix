## What's New in v3.23.0-fix.19.1

> [!TIP]
> **UI Optimization Update:** This release focuses on refining the Fleet Bandwidth Hub dashboard for a cleaner, more accurate monitoring experience. All core features from v3.23.0-fix.19 are preserved.

### Installing / Updating

**Binary (bare metal / VM):**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update -t v3.23.0-fix.19.1
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.19.1
```

### 🗺️ Fleet Bandwidth Hub Dashboard (Optimized)

![Hub Dashboard Preview](https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/main/docs/hub-dashboard-preview.png)

A live fleet monitoring dashboard that aggregates bandwidth reports from all provider nodes in real time.

> [!IMPORTANT]
> **v19.1 UI Improvements:**
> - **Consolidated Node View:** Merged redundant "Host" and "Node" columns. The Node column now displays both the ID and Version for a higher-density data view.
> - **Precise Alignment:** Fixed numerical header offsets; all stats (Clients, RX, TX, Mbps, Heap, Conns) are now perfectly right-aligned with their data cells.
> - **Expanded Detail Depth:** Refined the per-proxy drilldown table layout for better readability on high-volume nodes.

**Key features:**
- **Per-node traffic rates**: RX/TX Mbps calculated as delta between consecutive reports.
- **Billable vs total traffic**: Summary bar and node rows show billable bytes in muted `b` text.
- **Auto-refresh**: 30s countdown with toggle checkbox.
- **Sortable columns**: 11 optimized columns with numeric-aware sorting.
- **JSON API**: `GET /api/nodes` returns full node state for external tooling.

### ⏳ Proxy Startup Pacing & Warmup Monitor

Starting a provider with a large proxy list (500+) no longer causes a thundering-herd against the platform WebSocket endpoint.

**Jittered Stagger:** Each proxy goroutine waits `index × stagger_ms ± 50% jitter` before dialing. Default stagger is 1s per proxy.

**Pace Monitor:** Background goroutine logs warmup progress every 30s:
```
[pace] ⚠ warmup: 47/200 up (24%), 150 connecting, 3 done
[pace] warmup: 142/200 up (71%), 55 connecting
[pace] ✓ warmup: 196/200 up (98%), 4 connecting — done
```

### 🔧 Stability & Improvements

**Port upstream proxy-fixes2:** Backported [upstream PR #184](https://github.com/urnetwork/connect/pull/184) (OOB provide-ack and ping-companion-contract). Improves reliability during backend outages.
