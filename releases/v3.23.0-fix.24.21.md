## Highlights

### ⚙️ Runtime Tuning — New `urnet-tools` Commands (#159)

Two new commands let you change provider behavior on the fly. Changes take effect on the next provider tick — no restart needed.

**`urnet-tools fast-auth [on|off]`** — toggle the auth rate limiter bypass:
```sh
urnet-tools fast-auth on      # bypass rate limiter immediately
urnet-tools fast-auth off     # re-enable rate limiter
urnet-tools fast-auth         # show current state
```

**`urnet-tools set [<key> [<value>|off]]`** — view or change any runtime override:
```sh
urnet-tools set                            # show all active overrides
urnet-tools set report-interval 60s        # post stats every 60s instead of 5m
urnet-tools set proxy-url-max 500          # cap URL-sourced proxies at 500
urnet-tools set proxy-url-refresh 15m      # re-fetch URL proxy list every 15m
urnet-tools set node-name ny1-box3         # change hub identity label
urnet-tools set cleanup-scope degraded     # cleanup job targets degraded proxies
urnet-tools set cleanup-interval 6h        # run cleanup every 6 hours
urnet-tools set report-interval off        # clear override, revert to startup default
```

### 📊 Hub Dashboard — Chart and Earning Fixes (#158)

**Fleet charts (Nodes tab):** The sparkline was plotting cumulative totals (monotonically increasing, unreadable). Now shows 4 charts in a 2×2 flex grid:
- Healthy proxies + active clients over time
- Hourly traffic deltas (RX/TX per hour window)
- Billable traffic per hour
- Peak clients + reporting nodes

**History chart (History tab):** Was interleaving every node's data as separate line segments at the same X positions. Now aggregates by hour, summing RX/TX across all nodes. Negative deltas from reporting gaps clamped to zero.

**Earning seeding fixed:** `prevBillable` was initialized to zero on restart, causing the first report cycle to always show 0 earnings. Now seeded from per-proxy IDs in the DB — earning is accurate from the first report after restart.

**Proxy drawer routing fixed:** `/api/nodes/<id>/proxies` was unreachable due to a routing conflict — the drawer silently failed to load. Now defaults to sort by active clients descending (then billable RX), with sortable columns and 90vw width.

**`/api/nodes` response includes earning field** so summary cards reflect live earning state.
