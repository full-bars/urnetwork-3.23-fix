# v3.23.0-fix.36.0

**Released:** 2026-11-20.

Previous release: [v3.23.0-fix.35.11](https://github.com/full-bars/urnetwork-3.23-fix/releases/tag/v3.23.0-fix.35.11).

This release redesigns the status command, adds proxy UDP relay coverage sweeps, introduces independent extender carrier controls, and brings the interactive top dashboard to Docker containers. It adds gossip diagnostics that you read on the host with `urnet-tools extender events` and removes an unused client window.

Update and restart the provider to use the new binary. Successfully changing extender carrier settings restarts the active extender role.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Quick start

Install on Linux or macOS:

```sh
curl -fSsL https://install.fullbars.xyz | sh -s -- install
```

Install on Windows in PowerShell. Windows Defender can flag the one-line form as a false positive, because the script downloads and unpacks a program. The safer way has two steps. Download the script, read it, then run it from disk:

```powershell
irm https://dl.fullbars.xyz/install-win.ps1 -OutFile "$env:TEMP\install-win.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-win.ps1"
```

The Installation guide lists the Defender labels you may see and what to do about them.

Run the provider in Docker. Use a single-use auth code from https://ur.io and keep the state volume:

```sh
docker run -d \
  --name=urnetwork \
  --pull=always \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  --sysctl net.ipv4.ip_forward=1 \
  --log-driver=json-file \
  --log-opt max-size=10m \
  --log-opt max-file=3 \
  -e AUTH=authcode \
  -e AUTHCODE='YOUR_AUTH_CODE_HERE' \
  -e HOST_HOSTNAME=$(hostname) \
  -v urnetwork_data:/root/.urnetwork \
  -v /path/to/proxy.txt:/app/proxy.txt \
  ghcr.io/full-bars/urnetwork-3.23-fix:latest
```

This release is the provider line. For miner setup, use the separate miner release and its instructions. This workflow does not publish a miner image.

On FreeBSD, run the installer as a non-root service account with sudo:

```sh
fetch -qo - https://install.fullbars.xyz | sudo sh -s -- install
```

On OpenBSD, choose an existing non-root service account and replace `urnet` with its name:

```sh
ftp -o urnet-install.sh https://dl.fullbars.xyz/install-openbsd.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

## What's changed

### Added

- **`urnet-tools status` redesign. [redeploy]** Default output is a one-screen health summary showing version, time-boxed cached update availability, proxy pool counts, UDP coverage, extender state, unit health with SIGPIPE restart risk detection, and resource utilization. `--brief` reports warnings and failures with script exit codes (0 healthy, 1 warning, 2 broken, 3 unreachable). A healthy brief result prints nothing. `--json` continues to print the raw provider snapshot. `--json-summary` prints the summary as a stable schema document (`urnet-tools-status/1`) and omits `jwt_expires` when the provider has no token. `--live` (and `-l`) refreshes the summary in place with cursor home on terminals (`--interval` to adjust rate). `--detail` restores the platform status output. ([fc71ab9](https://github.com/full-bars/urnetwork-3.23-fix/commit/fc71ab9756514e0e8ccccf837248fb5ec464836b), [5f9e842](https://github.com/full-bars/urnetwork-3.23-fix/commit/5f9e842eaf20b2a3293712a06e8ae2938e392fb1), [66f8e4b](https://github.com/full-bars/urnetwork-3.23-fix/commit/66f8e4b34c4569b361681d0ba20f0010da8e7d16))
- **Proxy UDP relay coverage. [redeploy]** Status, `top` and metrics report UDP relay coverage for online proxies. Background sweeps check paid and URL proxy sources. A check still running after 20 seconds is treated as unknown and allowed. Proxies are never rejected or graded down for lacking UDP. Only client UDP and QUIC flows are refused through a proxy proven not to relay (`no-relay` or `exit-mismatch`). Turning off the proxy sweep with `urnet-tools set udp-probe off` stops new sweeps at the next tick. A running sweep continues. The probe state file is written in the background at most every 2 seconds during normal operation. Shutdown can request an immediate flush. A remembered TCP exit is reused for at most six hours. The shared source line classifier rejects unbracketed IPv6 lines as `invalid_fields`. ([ac6ca8c](https://github.com/full-bars/urnetwork-3.23-fix/commit/ac6ca8cdcf516ba74b5df24600936a813b72539e), [93082d8](https://github.com/full-bars/urnetwork-3.23-fix/commit/93082d897c5dd58a0d2b93e7eaf0fcfcdc388500), [b94d6e4](https://github.com/full-bars/urnetwork-3.23-fix/commit/b94d6e4e4e1bbed4d505f0e3051f20440b87f70a))

### Operator actions (needs-fleet-deploy)

- **New settings:** Operators can control optional extender carriers (`extender-udp443`, `extender-udp4053`, `extender-udp53`) and the proxy sweep (`udp-probe`) via `urnet-tools set`.
- **Restart behavior:** Successfully changing an extender carrier setting restarts an active extender role. A failed carrier setting write does not restart a healthy role.
- **Extender port 53 sysctl threshold:** `extender setup --route=sysctl --udp53` can set the threshold on Linux after a typed `yes`. Without the flag, binding port 53 still requires `cap_net_bind_service` or manual sysctl configuration.
- **Head tier and proxy slots:** A provider that sends the proxy header counts at no head tier unit. Bind direct devices only, and keep a direct slot on the host that you bind.
