# v3.23.0-fix.30.5 — 2026-08-22

> [!NOTE]
> Operators should update the Go tools (`urnet-tools`, `urnet-docker`) to pick up in-place container updates and real per-command help. The provider toolchain moves to Go 1.27. This release is CLI- and tooling-focused; the provider network stack itself does not change.

## 1. Summary

This release migrates `urnet-tools` and `urnet-docker` CLI routing to Cobra, adds an in-place container update path with real per-command help pages, bumps the build toolchain to Go 1.27, and confirms `greenteagc` is a genuine upstream Go experiment verified viable on the new toolchain. CI now skips the heavy build gauntlet on docs-only PRs and treats VirusTotal scan timeouts as non-blocking. Release notes for v3.23.0-fix.30.4 are updated with Microsoft's confirmation that the flagged Windows binaries were false positives.

## 2. CLI: Cobra Migration and In-Place Container Updates

- **Cobra Routing (PR #448)**: `urnet-tools` and `urnet-docker` CLI dispatch moves from hand-rolled argument parsing to Cobra. This is the foundation for the per-command help added in PR #453.
- **In-Place Container Update (PR #453)**: `urnet-docker update <target flag>` runs the in-container provider self-update without recreating the container, gated behind a confirmation prompt.
- **Real Per-Command Help (PR #453)**: `urnet-docker proxy` is now a Cobra parent command with 12 per-subcommand help pages. `exec -h` and many other commands on both `urnet-tools` and `urnet-docker` show real Usage/Examples help instead of a flat list.

## 3. Toolchain: Go 1.27

- **Go 1.27.0 (PR #449)**: Bumps `go.mod` from 1.26.4 to 1.27.0, pins CI `go-version` to 1.27, and moves the Dockerfile and `hub/Dockerfile` builder base images to `golang:1.27-alpine`. README and docs now state Go 1.27.
- Verified on stock Go 1.27: build, vet, and the full `-short -race` test suite pass. The full cross-compile matrix, including `386` and the `mips`/`mipsle`/`mips64`/`mips64le` targets, builds clean. No `go.mod` dependency changes were required, and a functional smoke test passed.
- **`greenteagc` Confirmed Viable (PR #450)**: `greenteagc` is an upstream Go experiment bundled in stock Go 1.27, not a fork-specific source patch. The provider builds and runs clean under `GOEXPERIMENT=greenteagc` on 1.27.

## 4. CI: Docs-Only Fast Path and Non-Blocking Scan Timeouts

PR #452 makes two changes to the release pipeline:

- Docs-only PRs skip the heavy build/test gauntlet via `paths-ignore`, so a documentation change no longer waits on the full cross-compile and race-test matrix.
- The VirusTotal scan script (`vt-scan.py`) records `UNKNOWN` instead of failing the job when an upload, lookup, or analysis call times out. Only a genuine malicious hit over the fail threshold still fails the job.

## 5. Documentation

PR #451 updates the v3.23.0-fix.30.4 release notes to record that Microsoft confirmed the `Trojan:Win32/Wacatac.C!ml` detections on the 30.4 Windows binaries were false positives and removed the detection. This release's Windows binaries carry the same stripped-Go build signature and may trip the same Defender heuristic again before Microsoft clears this build's hashes; the false-positive removal steps documented for 30.4 (`MpCmdRun.exe -removedefinitions -dynamicsignatures` then `MpCmdRun.exe -SignatureUpdate`) apply here too.
