## 🗂️ What's New

### 🌐 Hub Server

**OPAQUE PAKE-based Hub Join** — PR #284
The hub now supports a password-authenticated key exchange (OPAQUE) join flow. Providers authenticate with a one-time registration against the hub's root password, establishing persistent credentials without exposing the password over the wire. Includes full tamper-resistance and concurrent-join test coverage.

**Docker-backed Hub Install/Update** — PR #278
`urnet-tools hub install --docker` and `urnet-tools hub update` now work on Linux, macOS, and Windows — the hub runs in a Docker container with the same `--tag`, `--port`, and `--docker` options. Bare-metal hub install is unchanged.

**Hub Dashboard HTTP Basic Auth** — PR #282
The hub dashboard and read-only API now support HTTP Basic Auth. Configure with `URNETWORK_HUB_USER` and `URNETWORK_HUB_PASSWORD` env vars before `hub init`.

**Auto-bootstrap Hub CA Cert from Env Vars** — PR #281
The hub's CA certificate can now be bootstrapped from `URNETWORK_HUB_CA_CERT` and `URNETWORK_HUB_CA_KEY` environment variables, eliminating the manual cert-distribution step for automated fleet deployments.

**CA Cert Hot-Reload** — PR #279
The provider and hub now detect `hub_ca.pem` changes at runtime and reload without restart — no more scheduling downtime for certificate rotation.

### 🧭 Custom Network Configuration

**choose_network — Persisted Custom API/Connect URLs** — PR #288
Two new environment variables let operators point the provider at a custom backend:
- `UR_API_URL` — custom API URL (default `https://api.bringyour.com`)
- `UR_CONNECT_URL` — custom WebSocket signaling URL (default `wss://connect.bringyour.com`)

Both are applied once at startup via `provider choose_network` and persisted to `~/.urnetwork/network.json`, so they survive restarts. Must be set together. Documented in `urnet-tools` and all relevant guides.

### 🚀 Provider Profiles

**Auto Tier 4 Extreme** — PR #280
The `auto` profile now has a fourth tier matching `turbo-v8` settings, reached at 8 GiB+ RAM. Auto profile progression is now:
- Tier 1 (< 1 GiB): lowmem
- Tier 2 (1–2 GiB): eco
- Tier 3 (2–8 GiB): turbo-v4
- Tier 4 (8 GiB+): turbo-v8

### ⏱️ Startup

**URNETWORK_SKIP_AUDIT** — PR #285
Set `URNETWORK_SKIP_AUDIT=1` to skip the startup system audit (disk speed benchmark, ulimit, conntrack checks). Useful in Docker where host sysctls aren't visible inside the container. The audit skip is also logged so it's visible in startup output.

### 🔒 Subnet Integration

**Subnet CLI Commands (Phase 4)** — PR #273
Wires the `sn` subnet CLI commands (`wallet set`, `claim`, `bind-head`, `unbind-head`) into the provider binary. These are inert in this release — no subnet consensus interaction is active yet; the commands expose the underlying `urfoundation/sn` library surface for testing.

### 🛠️ Performance & Fixes

**Upstream gopacket Removal + IpAssoc Wiring** — PR #263
Ports upstream commit ee7a476, removing the gopacket dependency and wiring IpAssoc into the transfer layer. Library-currency only — no provider-facing behavior change.

**DNS Default Changed to Quad9** — PR #287
The default local DNS resolver now prefers Quad9 (`9.9.9.9`) over Cloudflare (`1.1.1.1`) for improved privacy posture. Falls back to Cloudflare if Quad9 is unreachable.

**Hot-Restart Warning Fix** — PR #277
`urnet-tools restart` now checks whether hot-restart is actually enabled before warning about JWT expiry — if hot-restart is on (the default), the warning is suppressed since the JWT is reused transparently.

**First JWT Refresh Log Fix**
Fixed a cosmetic bug where the first JWT refresh log showed a saturated duration ("never") instead of a human-readable message.

**Test/CI Hardening** — PR #286
Fixed a leaked `AddrGenerator` goroutine in tests, hardened TLS test timeouts, and bumped a stale 45s deadline that caused CI flakes.

## ⚠️ Breaking Changes

**(None. Drop-in upgrade.)** All new features are additive and opt-in. Existing configurations, profiles, and API endpoints continue to work unchanged.
