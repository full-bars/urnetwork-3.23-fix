### **v3.23.0-fix.26.3 — Performance Overhaul, Hub PAKE Auth, & Network Selection**

This release introduces major performance upgrades via upstream gopacket removal and memory budgeting infrastructure. It also ships the OPAQUE PAKE-based hub authentication prototype, custom network selection, and Docker-backed hub updates.

### **Highlights**

> [!TIP]
> Providers can now select custom API and Connect URLs persistently using the `choose_network` flow, or by passing `UR_API_URL` / `UR_CONNECT_URL` to Docker environments.

> [!IMPORTANT]
> The performance improvements from PR 263/264 prevent severe memory thrashing, pool exhaustion, and CPU hot-spinning during contract creation. Upstream gopacket parsing has been entirely replaced with the more efficient `IpAssoc` wiring.

### **New features**

• **Custom Network Selection**: Persist custom API and connect endpoints using `choose_network`.
• **Hub PAKE Authentication**: Implements OPAQUE PAKE-based provider joins with credential authentication.
• **Subnet CLI Tools**: Introduces `wallet set`, `claim`, `bind-head`, and `unbind-head` commands for advanced network management.
• **Docker Hub Updates**: Fully automates Docker-backed hub installations and updates for Linux, macOS, and Windows.
• **System Audit Bypass**: Added `URNETWORK_SKIP_AUDIT=1` for optionally skipping startup system checks.
• **Auto Tier 4**: Added `auto Tier 4 (extreme)` profile matching turbo-v8 scaling settings.
• **Hub Basic Auth**: Introduces HTTP Basic Auth to the Hub dashboard and read-only API.
• **Auto-bootstrap Hub CA**: The Hub CA certificate can now bootstrap automatically from token environment variables.

### **Fixes and hardening**

• **Performance & Memory Overhaul**: Upstream `gopacket` removal and `IpAssoc` wiring deployed alongside critical memory pool capacity sizing, queue budgeting, and contract stat fixes.
• **DNS Resilience**: Defaults local DNS resolution to Quad9 first, falling back to Cloudflare.
• **Hot-Restart Warnings**: Dedups hot-restart warnings and ports Worker fallback logic to Windows and macOS.
• **CA Certificate Reloads**: Dynamically reloads CA certificates when `hub_ca.pem` changes without requiring a restart.
• **Test Hardening**: Plugs a leaked `AddrGenerator` goroutine and hardens TLS test timeouts.

### **Upgrade notes**

• **New & Existing Installs**: No manual action required. Your nodes will fetch the update and transition smoothly.

### **Verification**

Verified end-to-end performance and stability on the `detroit` test node over 12 hours. Confirmed elimination of CPU hot-spin and `nil-map` panics during contract creation, and validated memory capacity is holding stable at ~30MiB with 99.9% pool reuse.
