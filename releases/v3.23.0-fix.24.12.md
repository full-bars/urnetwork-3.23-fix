## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.12
```

## What's New

### `urnet-tools update` now actually updates itself

`urnet-tools update` had a bug where it would silently skip fetching the latest `urnet-tools` script from GitHub — a stale `[ -n "$URNET_INSTALL_URL" ]` guard (only set for dev/testing overrides) meant every update reinstalled the old script from disk instead of the latest version.

Now the script is fetched from three sources in priority order:
1. **Tarball-bundled** — the release tarball now includes `urnet-tools` alongside the binary, so updates work even without GitHub access
2. **GitHub raw** — fresh script from the latest release
3. **Current script** — fallback if both above fail

The `-i`/`--important` flag (from v24.11) and `-f` (force update) now work reliably after running `urnet-tools update` because the latest script is actually installed.
