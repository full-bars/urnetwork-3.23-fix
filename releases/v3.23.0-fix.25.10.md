# 📊 v3.23.0-fix.25.10 — Hub Charts + AI Ops Guide

> **TL;DR** Fixed chart-axis overflow on high-traffic fleets and added three new hub dashboard charts — Mbps throughput, Billable %, and Contract Win Rate. New `AI.md` operations guide for automated fleet management. CI Discord webhook formatting fix.

---

## 📊 Hub Dashboard Charts

- **Chart overflow fixed** — high-traffic fleet charts no longer clip at the upper bound
- **Mbps throughput chart** — raw RX/TX in megabits per second
- **Billable % chart** — ratio of billable bytes to total traffic
- **Contract Win Rate chart** — acquired vs denied contracts over time
- Fixed a stale auth flow reference in `AI.md`

## 📖 AI Operations Guide (`AI.md`)

Comprehensive operations guide covering provider authentication, proxy management, hub dashboard setup, monitoring, and troubleshooting — designed for automated fleet operations. Includes correct auth flow procedures and references to existing documentation.

## 🔧 CI Discord Webhook

Split multi-line Docker pull commands into individual code blocks so Discord embeds render them correctly.

## 📦 Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
urnet-tools hub update
```

```sh
# 🐳 Docker provider (GitHub Container Registry)
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.25.10

# 🐳 Docker hub (GitHub Container Registry)
docker pull ghcr.io/full-bars/urnetwork-3.23-fix-hub:latest

# 🐳 Docker hub (Docker Hub)
docker pull 3cape/urnetwork-hub:latest
```
