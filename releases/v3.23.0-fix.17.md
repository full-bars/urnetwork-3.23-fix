## What's New in v3.23.0-fix.17

curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/main/scripts/Provider_Install_Linux.sh | sh

📦 **Release Notes: v3.23.0-fix.17**

Release Date: June 5, 2026

> [!TIP]
> **Accountability Check:** The new Unified Telemetry system provides 100% wire-transparency. You can now compare the "TOTAL" column (raw wire bytes) against the "BILLABLE" column to calculate the exact protocol overhead (H1/H3 heartbeats vs NAT payload) for every proxy in your fleet.

🔄 **Proxy Hot-Reload (New in .17)**

Proxies can now be added and removed from a running instance **without a restart**—preserving warm state across your entire fleet. This is the flagship feature of this release.

- `urnet-tools proxy refresh` — Apply your updated proxy config with a diff preview and confirmation prompt
- `urnet-tools proxy remove-dead` — Interactively remove dead (never-authenticated) or inactive (long offline) proxies
- `urnet-tools proxy health` — Stream live proxy status and recovery events
- Stable slot IDs — Re-added proxies automatically restore their original proxy[N] slot number

> [!IMPORTANT]
> Proxies take 8-12 hours to fully warm up on the platform. Previously, removing a single dead proxy required a full restart, wiping the warm state of every live proxy on the machine. That is no longer the case.

**Tip:** Triggering a reload that results in an empty proxy list will exit the provider cleanly. This can be used as a controlled shutdown without sending SIGTERM.

📊 **Unified Proxy Telemetry (New in .17)**

**Per-Proxy Bandwidth Tracking:** The provider tracks cumulative bandwidth per proxy: bytes sent and received, broken down into billable (user-attributed) vs. total (including protocol overhead). Updated every heartbeat and persisted to `proxy_traffic.state` on the config volume.

**Active NAT Session Tracking:** The `CLIENTS` counter in the traffic report (and the `clients=N` field in `[net][s]select` logs) shows the number of active NAT sessions currently multiplexed through each proxy.

**Dialer-Level Accounting:** By tracking at the Dialer layer, we now capture 100% of wire traffic, including internal heartbeats and platform overhead that previously bypassed the NAT counters.

Monitor with:
```bash
urnet-tools proxy traffic
```

📋 **Provider Logs Command (New in .17)**

Streams live provider logs to stdout. On RAMLOGS-enabled installs (lowmem, eco, or slow-disk auto-detected) it tails `/dev/shm/urnetwork.log`; otherwise it follows `journald`.

```bash
urnet-tools logs
```

For Docker, the right command depends on whether RAMLOGS is enabled:
```bash
docker logs -f urfix                                # RAMLOGS off (logs go to stdout)
docker exec urfix tail -f /dev/shm/urnetwork.log   # RAMLOGS on (logs go to RAM disk)
```

🔧 **Stability & Fixes (New in .17)**

**[net][s]select Error Suppression:** Transient proxy connection errors were previously logged on every failure, creating significant log spam on busy or partially-degraded deployments. These errors are now rate-limited to at most one per minute, keeping logs readable without losing signal.

**Clients Counter Fix:** The `CLIENTS` column in `proxy_traffic.state` and the `clients=N` field in `[net][s]select` logs were always showing `0` because the clients counter was not being copied into bandwidth snapshots. This is now corrected.

**Numeric Proxy Sorting:** Fixed proxy IDs to sort numerically instead of lexicographically (proxy[2] now comes before proxy[10]).

🛡️ **E2E Post-Quantum Encryption: Foundation**

> [!NOTE]
> Encryption is **disabled by default** in this release. No behavior change for existing deployments.

This release ports urnetwork/connect#183 into the fork. The upstream PR introduces end-to-end encryption between provider and client using TLS 1.3 with the `X25519MLKEM768` post-quantum hybrid KEM (ML-KEM / Kyber), per-peer identity verification via Ed25519 signatures, and AES-256-GCM AEAD. It also hardens contract reliability: `CloseContract` now uses confirmed delivery instead of fire-and-forget.

The full implementation is present and building in this fork but inactive (`Encrypt: false`, `TlsTimeout: -1`). It will be enabled in a future release following the upstream rollout plan.

📦 **Installer Improvements**

- `urnet-tools` now accepts a global `-t <tag>` flag for pinning to a specific version on any subcommand
- Install URL is now configurable via `URNETWORK_INSTALL_URL` for self-hosted setups
- `install` and `auth-provide` now prefer the locally running script over fetching from GitHub when possible
