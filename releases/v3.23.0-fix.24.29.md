## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.29
```

```sh
docker run -d \
  --name=urfix \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  -e URNETWORK_AUTH_CODE=*** \
  -e HOST_HOSTNAME=$(hostname) \
  -v urfix_config:/root/.urnetwork \
  ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.29
```

## What's New

### Fleet-Wide Per-Proxy Analytics + Multi-Page Dashboard (PR [#184](https://github.com/full-bars/urnetwork-3.23-fix/pull/184))

I rebuilt the hub's data pipeline and dashboard to give operators per-proxy visibility across the entire fleet. Every provider bandwidth report now writes sparse deltas per (node, proxy, hour) into a tiered SQLite schema: `proxy_node_hourly` (90d), `proxy_node_daily` (13mo), and `proxy_fleet_daily` (forever). A background goroutine handles hourly rollups and retention pruning automatically, using a high-water mark to prevent double-counting.

**Three new read APIs:**
- `GET /api/proxies/top?window=&sort=&node=&limit=` — proxy leaderboard sorted by traffic, contracts, or denials
- `GET /api/proxies/history?addr=&window=&split=node` — per-proxy time series with optional per-node comparison
- `GET /api/nodes/contracts?node=&window=` — per-server won/denied contract rates from `node_hourly`

**Dashboard overhaul:** Replaced the two-tab layout with a four-page sidebar-navigated application:
- **Overview** — summary cards plus five fleet mini-charts (traffic, billable, clients, nodes, contracts/hr)
- **Servers** — the existing sortable/filterable node table with per-node proxy drawer
- **Proxies** — leaderboard from `/api/proxies/top` with time-window pills (1h/24h/7d/30d/1y), sort dropdown, node filter, color-coded win%, and a collapsible idle section
- **Contracts** — fleet won-vs-denied uPlot chart plus per-server table sorted by win rate with green/red split bars; clicking a server row opens its proxy drawer

### Pattern-Based Proxy Removal (PR [#183](https://github.com/full-bars/urnetwork-3.23-fix/pull/183))

Removing all proxies matching a pattern (e.g. every `dc.decodo.com` entry) previously required resetting the entire proxy list and restarting the provider. Now you can do it with a single command — no restart needed, unaffected proxies keep serving.

```sh
urnet-tools proxy remove --match=dc.decodo.com --preview   # preview only
urnet-tools proxy remove --match=dc.decodo.com             # prompt, then remove
urnet-tools proxy remove --match=192.3. --yes              # skip confirmation
```

Matching is case-insensitive against the proxy **host only** (never port, user, or password). Removal patterns are persisted to `proxy_url.json`'s exclude list, so URL source refreshes won't re-add matching proxies. New `proxy exclude` subcommand manages the pattern list, and `proxy summary` shows active patterns.
