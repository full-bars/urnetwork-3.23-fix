## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update -t v3.23.0-fix.20.1
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.20.1
```

```sh
docker run -d \
  --name=urfix \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  -e URNETWORK_AUTH_CODE=YOUR_AUTH_CODE \
  -e HOST_HOSTNAME=$(hostname) \
  -v urfix_config:/root/.urnetwork \
  ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.20.1
```

## What's Fixed

### 🔧 urnet-tools Update Resilience

Fixed `urnet-tools update` command compatibility on systems where API response parsing may fail. Now gracefully falls back to version string comparison instead of aborting with a misleading error. Improves reliability across different shell environments.

### ⚡ Parser Optimization & Contract Expiry (PR#185 Adoption)

Adopted upstream PR#185 improvements: fast-path protocol buffer parser and streamlined 120-second contract expiry cleanup. Reduces parser overhead and improves contract lifecycle efficiency.
