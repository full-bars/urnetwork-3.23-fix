# v3.23.0-fix.35.4

## Quick start

Install on Linux or macOS:

```sh
curl -fSsL https://install.fullbars.xyz | sh -s -- install
```

On FreeBSD, run the installer as a non-root service account with sudo:

```sh
fetch -qo - https://install.fullbars.xyz | sudo sh -s -- install
```

On Windows, use PowerShell:

```powershell
irm https://dl.fullbars.xyz/install-win.ps1 | iex
```

Run the provider in Docker with a persistent volume and a single-use auth code from https://ur.io:

```sh
docker run -d --name urfix --pull always --restart unless-stopped --cap-add NET_ADMIN --cap-add NET_RAW --sysctl net.ipv4.ip_forward=1 -e AUTH=authcode -e AUTHCODE='YOUR_AUTH_CODE_HERE' -v urnetwork_data:/root/.urnetwork ghcr.io/full-bars/urnetwork-3.23-fix:latest
```

This release is the provider line. For miner setup, use the separate miner release and its instructions; this workflow does not publish a miner image.

## What changed

- We added `urnet-tools diag` to capture heap and goroutine profiles and, when available, a CPU profile from a running provider. Bundles may contain sensitive data. [redeploy]
- We report H1+ handshake failures by cause. Use the class metrics or the total, not both together. [redeploy]
- We stop rewriting an unchanged client JWT store and report why completed writes occurred. [redeploy]
- We retire degraded URL proxies after the configured down window, six hours by default. Trim-held proxies are protected. [redeploy]
- We honor metrics disable values in `URNETWORK_METRICS` over saved state. [redeploy]
- We fixed Windows IPv6 egress binding when an embedding caller configures an interface. H3 logs a failed UDP bind and still tries the connection. This provider tree does not set an egress index itself. [redeploy]
- We fixed a shared UDP socket leak, clipped wide characters in the TUI and FreeBSD fallback PID matching. [redeploy]
- We restore the Linux extender bind capability after a provider binary swap and warn if it cannot be verified. The extender remains a work in progress and does not activate for clients. [redeploy]
- We fixed argument forwarding for macOS proxy refresh and remove-dead commands. [redeploy]
- We removed the duplicate down count from the proxy health line and refreshed the SN25 live figures. [redeploy]

[redeploy] means update the provider binary or container to run the change.
