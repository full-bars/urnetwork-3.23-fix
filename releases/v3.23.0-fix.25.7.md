# 🔧 v3.23.0-fix.25.7 — SQLite Index Hint Hotfix

> **TL;DR** Forces `INDEXED BY` on the live-tail `proxy_node_hourly` scan so SQLite doesn't pick the wrong index for "all nodes" leaderboard queries. No provider changes.

---

## 🐛 Force Index Hint

The hub's live-tail query for the proxy leaderboard was relying on SQLite's query planner to pick the right index — and it was picking the wrong single-column index on "all nodes" queries. Now uses `INDEXED BY idx_pnh_hour_proxy` to force the correct composite index, matching the behavior added for the main dashboard queries in 25.6.
