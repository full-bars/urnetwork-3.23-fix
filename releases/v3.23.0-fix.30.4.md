# v3.23.0-fix.30.4 — 2026-08-22

> [!NOTE]
> Operators should update provider nodes to pick up critical memory limits, adaptive GC consolidation, loopback observability, and same-user privilege fixes. The Go tools (`urnet-tools`, `urnet-docker`) receive major expansions including restored auth/session/hub command families, proxy trim with active earning protection, and full Docker CLI parity. The hub binary ships alongside this release.

## 1. Summary

This release delivers major stability, observability, and command parity updates across the provider and tools suite. Highlights include universal finite memory bounds across all provider execution paths (ATL2 fix), consolidation of dynamic GC governor into a single adaptive controller, opt-in loopback pprof profiling and buffer pool metrics, persistent `proxy trim <N>` with active billable client traffic protection and F-tier eviction prioritization, restoration of legacy shell command families (`auth`, `choose-network`, `fast-auth`, `set`, `session save/load`, `hub`, `self-heal`), resolution of same-user systemd/journalctl privilege rejection on Linux, and full feature parity for `urnet-docker`.

## 2. Universal Finite Memory Limits & Adaptive GC Governor

- **Universal Memory Limit (PR #427)**: Guarantees a finite memory ceiling across every provider path and profile (tier 1/2 `--max-memory`, cgroup limits, and host available RAM boundaries), eliminating unbounded heap growth on constrained nodes.
- **Adaptive GC Governor (PR #428, #429)**: Retired the separate eco runtime monitor and consolidated dynamic GC tuning into a single `gcGovernor` in `resource_pressure.go`. The governor dynamically tightens `GOGC` below profile baseline based on the tighter of process heap fraction and host available RAM, backed by a 10s live-heap subtick to arrest rapid allocation spikes.

## 3. Proxy Management: Persistent Trim & Active Earning Protection

- **Persistent Proxy Trim (PR #442, #447)**: Introduces `urnet-tools proxy trim <N>` and `urnet-docker proxy trim <N>` to enforce a persistent hard cap on running proxies (`~/.urnetwork/proxy_trim`).
- **Active Earning Protection**: Proxies with active billable client traffic (`traffic > 0`) are protected against eviction. An active earner is never shed while idle proxies remain.
- **Eviction Hierarchy**: Dead/unhealthy proxies shed first, followed by proven failing F-tier nodes (`score < 0.60`), untested/probationary ungraded proxies (`effectiveTrimScore: 0.595`), and finally D $\to$ C $\to$ B $\to$ A tiers.
- **Scale Preservation**: Among active earners, smaller bandwidth streams shed before larger streams to preserve maximum operator revenue. Clamps AIMD `TargetPoolSize` and blocks over-budget additions during periodic reloads.

## 4. Diagnostics & Observability

- **Loopback Diagnostics & pprof (PR #423)**: Adds `URNETWORK_PPROF` opt-in listener restricted strictly to loopback interfaces (`127.0.0.1:6060`), exposing Go standard `net/http/pprof` endpoints. Non-loopback addresses are rejected.
- **Message Pool Metrics & Error Tracking (PR #425, #426)**: Exposes `/metrics/pool` and `/metrics/errors` on the loopback listener. Tracks buffer pool hits, misses, returns, active allocations, GC cycles, and categorized rate-limited error history across transport, IP, proxy, and WebRTC subsystems.

## 5. Restored Command Families in urnet-tools

- **Auth & Config (PR #439)**: Pure Go implementations of `auth`, `choose-network`, `fast-auth`, and `set [key=value]`.
- **Session Backup & Restore (PR #440)**: `session save <file>` and `session load <file>` export/import encrypted provider identities (AES-256-CBC with PBKDF2/SHA-256), featuring no-clobber protection, pre-load state backups (`~/.urnetwork.bak.<timestamp>`), and account verification.
- **Hub Management (PR #441)**: Complete hub command suite (`hub init`, `link`, `unlink`, `test`, `onboard-cmd`, `show-password`, `open-port`, `update`) with interactive CA verification and SHA-256 fingerprint pinning.
- **Status & Self-Heal (PR #438)**: Linux live `systemctl status` rendering for systemd units and `self-heal [on|off|status]` pressure monitor marker management.
- **Layout & Defaults (PR #409, #436, #437)**: Restored emoji-sectioned help styling, persisted provider targeting (`default set/show/clear`), and styled terminal status panels for Windows and macOS.

## 6. Linux Privileges, Installer & Docker Parity

- **Same-User Privilege Seam (PR #446)**: Eliminated `-M <user>@` on same-user `journalctl`, `systemctl`, `status`, and `restart` invocations, removing `Operation not permitted` / `systemd-machined` errors for non-root operators. Decoupled `optimize` from provider discovery with automated `sudo sysctl` escalation.
- **urnet-docker Parity (PR #445)**: Expanded host-side `urnet-docker` with full command parity matching `urnet-tools` (lifecycle, proxy management, auth, config, session, hub) and added `meso-miner` container discovery.
- **Installer & Packaging (PR #408, #424, #432)**: Dedicated installer route at `dl.fullbars.xyz/urnet-docker.sh`, optimized Docker builder layer caching, and hardened Windows multi-arch asset extraction.

## 7. Artifact Verification & Security Scanning

- **VirusTotal Pipeline Integration**: All 20 release binaries (`provider`, `hub`, `urnet-tools`, `urnet-docker` across Linux, macOS, and Windows on `amd64` and `arm64`) are scanned against the VirusTotal API upon tag creation. The pipeline enforces a two-tier gate: $\le 2$ detections pass (standard stripped Go compiler false-positive band), 3–10 flagged for review, and $>10$ detections hard-block.
- **ClamAV Anti-Malware Engine**: Release artifacts undergo independent offline verification via ClamAV with EICAR self-test validation to ensure multi-engine supply-chain integrity.
- **Microsoft Defender False-Positive Resolution**: The Windows binaries that VirusTotal flagged as `Trojan:Win32/Wacatac.C!ml` were submitted to Microsoft Defender for manual analysis. Microsoft classified each submission as an incorrect detection (a false positive) and removed the detection. If a cached detection remains on a machine, run `MpCmdRun.exe -removedefinitions -dynamicsignatures` then `MpCmdRun.exe -SignatureUpdate` as an administrator.
- **CFAA Security Blocklist (PR #412)**: Synchronized real-time CFAA malicious IP and interceptor blocklists with upstream to safeguard proxy traffic tunnels.
