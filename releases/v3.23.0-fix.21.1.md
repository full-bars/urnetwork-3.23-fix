## Highlights

### ⚡ CPU-Optimized Proxy Handling
Rewrote the internal `proxy_health.go` tracker to use an address-based pointer index. This completely eliminates global mutex lock contention and `O(N)` array scans when looking up proxy bandwidth limits. Heavy disconnects, hot-reloads, and mass reconnections are now vastly more CPU efficient.

### 📈 Utilization & Instrumentation
- **Dial Latency Metrics:** Injected a `dur=Xms` timestamp metric into all `[net][s]select` logs. This allows you to track real-world dial latency per strategy (fragment vs direct vs tls) directly from your log streams without altering dialing behavior.
- **Provider Utilization Logging:** Added a high-signal `[earn] proxies_up=N serving=M idle=K clients=C` utilization summary to the periodic heartbeat output so you can monitor your fleet's active earning capacity at a glance.
- **Traffic Logging Math:** Fixed a residual formatting bug where the `[traffic] total` line was printing `rx=X MB/s/s` instead of purely `MB/s`.

### 🛡️ TLS Deadlock Fix & Test Suite Stability
- **Deadlock Resolution:** Resolved a chronic lock-ordering inversion in the `EncryptionSessionManager` that could deadlock the provider during idle reaping and concurrent TLS handshakes. The architecture has been refactored to a push-model, fully isolating the state locks.
- **CI Reliability:** Eliminated transient test hangs and failures by hardening spin-lock yields and enforcing strict timeouts across the test suite.

### 🐳 Docker & Installer Resilience
- **Docker Pull Tag Consistency:** Modified the CI pipeline to preserve the full git-release tag string. Docker pulls using the exact semantic version no longer trigger `manifest unknown` errors.
- **Atomic Binary Replacement:** `urnet-tools update` now gracefully bypasses "Text file busy" lockouts during live binary replacements using an atomic Linux `mv` trick, eliminating the need to tear down the provider before pulling the update.
- **Forward-Compatible Flags:** Implemented graceful parsing within the CLI scripts so that future unsupported flags (like `-t`) won't catastrophically crash older `urnet-tools` versions.
- **Systemd Drop-in Scanning:** Hardened `urnet-tools logs` to intelligently scan all `.conf` files within the `urnetwork.service.d/` directory.
