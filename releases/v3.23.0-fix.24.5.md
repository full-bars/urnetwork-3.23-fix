## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

## What's Fixed

- **SOCKS5 probe no longer runs on file/internal proxy lists**: The pre-auth SOCKS5 reachability probe (`probeProxySocks5`) was running on every proxy, including operator-curated paid lists from proxy files. It was designed for free public URL lists where most entries are dead. File-based and internal proxies now skip the probe and go straight to auth, as they did before the probe existed. URL-sourced proxies added via hot-reload are still probed.
