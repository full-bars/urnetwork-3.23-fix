## Highlights

### 🐛 Error Logging for Reload Triggers and State Writes (PR #163)

`writeReloadTrigger()` and `writeProxyState()` were silently discarding errors. If the disk filled up or permissions changed, hot-reloads silently stopped working and proxy.state went stale -- no log, no alert. All 6 call sites now log a warning on failure.

### 🔒 DoH Certificate Pinning (PR #164)

The DNS-over-HTTPS resolver was building its own HTTP transport with no TLS client config. The field was commented out with a FIXME. Any attacker who could see your DNS traffic could MITM DoH responses. Now uses the same pinned ISRG Root X1/X2 certs as every other TLS connection the provider makes.

### 🛠️ Reload Watcher and Proxy Probe Fixes (PR #165)

Two operational hazards fixed: the reload watcher could spuriously trigger a full proxy reload on transient read errors (auth storm risk), and proxy probes could hang indefinitely if setting a deadline on a bad connection failed. Both now log errors and handle failures gracefully.

### 🧹 Dead Config Cleanup (PR #166)

Removed `LegacyCreateContract` and `TrackUsedContracts` from `ContractManagerSettings`. Both fields were always `false`, never set to `true` anywhere, and marked `// TODO remove`. Cleaned up referencing code paths and tests.

### 📝 Proxy Refresh Help Text Fixed

`urnet-tools proxy refresh` no longer claims it gracefully drops all connections. The real description: re-reads configs and hot-reloads proxies (adds new, removes absent, running proxies untouched).
