## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.23
```

```sh
docker run -d \
  --name=urfix \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  -e URNETWORK_AUTH_CODE=YOUR_AUTH_CODE \
  -e HOST_HOSTNAME=$(hostname) \
  -e PROXY_URL='https://example.com/your-proxy-list.txt' \
  -v /path/to/proxy.txt:/app/proxy.txt \
  -v urfix_config:/root/.urnetwork \
  ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.23
```

## Highlights

### 🎯 Earning Visibility — Know When You're Actually Moving Traffic
The two most important questions for any provider node — "am I earning?" and "are contracts being won?" — now have clear, real-time answers in the logs.
- **`[contract] acquired` / `[contract] denied`** are now logged for **every event**, with no 1/minute rate-limiting. Includes destination ID and contract size so you can trace exactly which peer is routing traffic through you.
- **`[traffic] total`** now includes `billable_today=X` (cumulative revenue bytes since midnight) and `earning=yes|no` — a single binary signal every 60s.
- **`[traffic]` per-proxy lines** unchanged: `billable_today=X` per address.

### 🔒 SOCKS5 Handshake Probe (not just TCP)
The reachability probe was upgraded from a bare TCP dial to a real SOCKS5 handshake. A proxy with an open port but a broken or non-SOCKS5 service behind it is now rejected at the probe stage — before it costs an auth attempt or a rate limiter slot.
- Applied to both the URL-source batch probe (pre-merge) and the per-retry probe in the auth loop.
- Tested against open-but-not-SOCKS5 endpoints to verify rejection.

### 🚦 Bounded Auth Concurrency
A new `proxyAdmissionMaxConcurrency = 5` semaphore caps how many auth calls can be in-flight at once. Previously, a slow SOCKS5 proxy timing out after 15s could pile up concurrent connections to the API even at 1 req/s. Now at most 5 auths are in-flight regardless of latency.

### 🧹 Unproven Proxy Overload Streak (Decay Instead of Full Clear)
When a never-proven proxy times out, the rate limiter now **decays** the overload streak by 1 instead of clearing it entirely on a success. With a 3-13% success rate against free public lists, outages now accumulate signal across failure clusters even with occasional successes mixed in.

### 📊 Rate Limiter Heartbeat
The shared auth rate limiter now logs `[proxy][authrate] still pinned at X req/s` every 60s when at the floor or ceiling, so operators can confirm it's alive rather than inferring health from silence.

### 🔄 Failure Count Resets on Success
A proxy that failed several times before finally succeeding no longer carries a permanent admission-gate weight penalty. Its failure history is reset on successful auth, so proven proxies compete on equal footing with untried ones.

### 📈 Retry Delay Scales with Attempt for All Errors
Previously only 429 errors scaled with attempt. Non-429 errors (timeouts, connection refused) now scale gently too: `(attempt-1) × 1s + jitter`, capped at 15s.

### 🔄 Give-Up Requeue Retry
If a URL-sourced proxy exhausts its auth attempts, the 15-minute requeue now checks whether the reload actually picked the address back up. If not, it fires a second trigger 30s later instead of leaving the address orphaned.

### 🛡️ Transport Keepalive Pings
`ControlPingTimeout` is now 30s (was 0 = disabled). The WebSocket/QUIC connection to the platform sends a small ping every 30s, detecting silently dropped connections within 30s instead of minutes.

### 🧠 RAMLOG Ring Buffer
The ramlog (`/dev/shm/urnetwork.log`) previously truncated to 0 at the 5MB cap, losing ALL history. Now it keeps the newest ~3.3MB and discards the oldest ~1.7MB — a rolling ring buffer compatible with `urnet-tools logs`.

### 🗂️ Proxy URL Robustness
- Overlapping fetch cycles prevented via mutex guard.
- `proxy add-source`/`proxy remove-source` now acquire the proxy lock before modifying state.
- Memory leak fixed: failure history and proven proxy sets are pruned every 60s.
- Custom HTTP client with 30s timeout and max 3 redirects instead of `http.DefaultClient`.
- Empty address guard for invalid `socks5://` lines.

### 🐛 Bug Fixes
- **Admission gate slot leak**: A race could permanently leak a concurrency semaphore slot, freezing all future auth attempts. Fixed.
- **Stale proxy lock**: `~/.urnetwork/proxy.lock` now stores PID + timestamp. After a crash, subsequent lock attempts detect and break the stale file.
- **CI cache noise**: Removed `~/go/pkg/mod` from cache to eliminate `tar: Cannot open: File exists` warnings.

## What's Changed
* fix: probe SOCKS5 handshake, not just TCP, before spending an auth attempt
* fix: bound auth concurrency, lower burst, decay unproven-streak, add rate heartbeat
* fix: reset lifetime failure count on success, scale non-429 retry delay with attempt
* fix: retry give-up requeue trigger if address still isn't running
* fix: rotating ring buffer for ramlog instead of truncating all history
* fix: remove contract log rate-limiting, add billable total + earning=yes|no
* fix: stop caching go module dir to eliminate tar extraction conflicts
* fix: enable transport keepalive pings (ControlPingTimeout=30s)
* fix: prevent admission gate concurrency slot leak on ctx cancel
* fix: detect and break stale proxy.lock after process crash
* fix: proxy URL robustness — overlapping fetches, lockless CLI, memory leaks
