## Highlights

### 🔒 DoH Now Uses System Cert Pool

`DefaultTlsConfig()` only pins ISRG Root X1/X2 — correct for `api.bringyour.com` but none of the four DoH providers (Cloudflare, Google, Quad9, OpenDNS) use Let's Encrypt. Every TLS handshake was failing silently, falling back to plain UDP DNS. DoH now uses Go's system cert pool automatically.

### 🛡️ `isHttpRequest` Detection (Upstream Port)

Ported from upstream b6ee955. Detects plaintext HTTP/1.x request lines in the DPI engine and returns `dmcaAllow` before the encrypted-traffic entropy heuristic fires, preventing false positives on radio/media streaming over non-standard ports. Checked after BitTorrent signatures so HTTP-tracker GET still classified correctly.

### 🛡️ Port Bounds Check (CodeQL Security Fix)

Added bounds check before `uint16` cast to prevent silent port overflow. Invalid ports now fall back to `defaultAPIPort` instead of wrapping to unexpected values.

## What's Changed
