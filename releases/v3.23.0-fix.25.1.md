## What's New

### 🧠 Core Networking

**HIGH — P2P transport setup blocked forever, dropping one direction of every bidirectional relay stream** — PR [#211](https://github.com/full-bars/urnetwork-3.23-fix/pull/211)

`NewP2pTransport()` started its connection-negotiation loop with `HandleError(p2pTransport.run)` — missing the `go`. Upstream runs this fire-and-forget (`go HandleError(p2pTransport.run, cancel)`); `run()` is a loop that only returns on stream teardown, so the synchronous call never returned.

`StreamSequence.Run()` needs two P2P transports for a bidirectional relay stream — one to the destination, one back to the source — calling `NewP2pTransport` twice in a row. Because the first call blocked for the stream's entire lifetime, the second call was unreachable code. Every bidirectional P2P stream ended up with only one direction's WebRTC transport ever negotiated; the other direction silently fell back to the lowest-priority gateway transport (routed through the platform's own servers instead of a direct peer hop). No error, no log — this has quietly degraded routing performance and relayed-bandwidth accounting on multi-hop streams since the fork's original branch from v3.23.

**Fix**: restore `go HandleError(p2pTransport.run, cancel)`. Added INFO-level logging (`[p2p]` transport start/stop, `[sm]` both-transports-created) so a regression of this kind shows up as a missing log line instead of failing silently.

**MEDIUM — Message pool buffer leak in DNS fragment reassembly** — PR [#211](https://github.com/full-bars/urnetwork-3.23-fix/pull/211)

Three leak paths in `combineQueue`/`decodeDns`, all fixed upstream but absent here: `RemoveOlder` dropped timed-out fragment sets without returning their pooled buffers; `Combine` overwrote a fragment slot on a duplicate/retransmitted index without returning the buffer it replaced; `decodeDns`'s goroutine had no shutdown drain for buffers still queued in `dnsCombineQueue`/`readPipeline` at teardown. Bounded by `DnsMaxCombine`/`DnsMaxCombinePerAddress`, but a steady, avoidable drain on the pool under sustained fragmented-DNS or retransmit traffic.

**Fix**: return buffers in all three paths. Added `TestCombineRemoveOlderReturnsPooledBuffers` and `TestCombineDuplicateIndexReturnsPooledBuffer` regression tests.
