# v3.23.0-fix.34.0-rc2

> **Built from:** `97b64d1d5` on `release/34.0`. Supersedes `v3.23.0-fix.34.0-rc1`; rc1 is not retracted. rc2 adds the two changes that merged into the release line minutes after rc1 was tagged.

> [!NOTE]
> Binaries differ from rc1 only by #897. #896 is CI-only. Everything in rc1 is included.

rc1 is already soaking on NY5 (installed 17:33 UTC, no restarts, ~1,050 proxies up, earning, 0 panics/storms). rc2 exists because #896 and #897 merged into the release line six minutes after rc1's tag was cut; the tag cannot move, so the next candidate carries them.

## What changed since rc1

- **A proxied TLS handshake can no longer strike or retry a family** (#897). `recordControlFamilyStrike` already rejected a `proxyDialError`, but a TLS handshake over a proxy fails with a plain timeout, so a proxied stall still demoted the proxy socket's family and then retried through the same proxy. The dial now checks `dialUsesProxy` at every decision: a proxied handshake records no family strike and is not retried on another family. Two regression tests cover the paths.
- **The modern-provider gate is enforced on every build** (#896). `build.yml` now runs `modern_provider_gate_test.go`, so the PQ (X25519MLKEM768) and resizable-window capability evidence cannot silently disappear from a release without CI failing. CI only; no provider behavior changes.

## What's Changed

- fix(control): never strike or retry a family from a proxied handshake (`289ecc334`, #897)
- ci: enforce the modern provider gate on every build (`be896c755`, #896)

## Deploy Notes

1. Replacing an rc1 canary needs only the provider binary; identities and state are unchanged.
2. The handshake guard matters on boxes with URL or churning proxies: it removes the last path where a proxy's own failure could demote a family and trigger a retry through the same proxy.
3. `urnet-tools` from this tag reports the rc2 version; the provider tarball's `urnet-tools` entry is the legacy shell script, the Go tool is the separate `urnet-tools-linux-amd64` asset.
