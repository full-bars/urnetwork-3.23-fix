## What's New

### 🔧 Orphaned PR #167 Fully Restored (isHttpRequest + DoH Rewrite)

PR #167 was merged (c99a13e) then entirely orphaned by a history rewrite — **both** its changes vanished from `main`. Only the CHANGELOG entry remained, claiming both shipped when neither did. This release restores everything that should have shipped in 24.25:

**DPI — isHttpRequest + Privileged Port Skip:**
- Plaintext HTTP/1.x request lines (GET, POST, etc.) now return `dmcaAllow` in the DPI flow state machine, before the encrypted-traffic entropy heuristic fires. Media/radio streaming over non-standard ports is no longer falsely dropped.
- Destination ports <1024 are allowed without payload inspection (a privileged port can't host P2P). Legitimate services like Telegram MTProto on 443 get through; peer traffic on high ports is still inspected.

**DNS-over-HTTPS Rewrite:**
- 4 providers configured by default: Cloudflare (JSON), Google (JSON), Quad9 (RFC 8484 wire-format), OpenDNS (RFC 8484 wire-format)
- Parallel queries with fastest-record-wins — first server to return records serves the answer
- Single-flight coalescing: concurrent identical queries share one resolution
- `MinCacheTtl` floors cache lifetime for zero-TTL records; `MaxConcurrentResolutions` bounds fan-out (default 64)
- Local DoH support: host-dialed HTTP client for sidecar resolvers
- LE cert pinning preserved: remote DoH over the tunnel uses the fork's ISRG Root X1/X2 pool; local DoH uses system pool

**Bug fix:** The DoH merge had a latent bug — when both NXDOMAIN and server timeouts occurred, the Miss flag was dropped, causing repeated cache misses and unnecessary queries. Fixed.

**Test coverage:** Ported upstream `ip_security_dmca_test.go` (13 tests) so future diffs against upstream fail loudly if any hunk is dropped.
