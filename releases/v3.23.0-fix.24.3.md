## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.3
```

## What's Fixed

- **`[c]ping` log spam**: With ControlPingTimeout=30s and thousands of connections, keepalive pings were producing ~33 lines/second of `[c]ping` output. Now suppressed globally to one line per 5 minutes: `[c]ping (14723 suppressed)`.
