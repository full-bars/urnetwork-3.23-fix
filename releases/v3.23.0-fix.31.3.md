# v3.23.0-fix.31.3

> [!CAUTION]
> The hub subsystem is being deprecated. The next release series (v32) removes it entirely. If you run hub mode, plan your migration now; hub-mode operators can stay on the 31.x series.

## What's Changed

### Bug Fixes
- **fix(provider): return pooled buffers on all drop/backpressure paths** — Fixed a memory leak where pooled byte buffers were not being returned to the pool on packet drop and backpressure paths. This reduces memory pressure on high-traffic provider nodes. ([#633](https://github.com/full-bars/urnetwork-3.23-fix/pull/633))

### Maintenance
- **chore(security): sync CFAA blocklist** — Two upstream blocklist refreshes:
  - IPv4: 42,791 → 47,286 → 42,872 entries
  - IPv6: 554 → 469 → 495 entries

**Full Changelog**: https://github.com/full-bars/urnetwork-3.23-fix/compare/v3.23.0-fix.31.2...v3.23.0-fix.31.3
