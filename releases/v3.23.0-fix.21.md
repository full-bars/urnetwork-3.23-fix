## What's New

### 🎛️ Hub Dashboard Setup Simplification

Three new `urnet-tools hub` commands for effortless bandwidth hub configuration without manual systemd edits or compilation:

**Set up hub reporting:**
```sh
urnet-tools hub set http://your-hub-host:8080
```

Works with https too (e.g., behind Caddy reverse proxy):
```sh
urnet-tools hub set https://hub.example.com:8080
```

**Disable hub reporting:**
```sh
urnet-tools hub off
```

**Install & run the hub binary as a systemd service:**
```sh
urnet-tools hub install
```

Hub binary is automatically downloaded from the release and runs as a user systemd service. Gracefully handles systems without systemd.

### 🔍 Clearer Authentication Error Messages

Fixed misleading auth failure logs. When proxies timeout connecting to the auth API, the log now correctly reports `"network error reaching API"` instead of suggesting JWT expiry. This makes it easier to distinguish between network issues and credential problems during troubleshooting.
