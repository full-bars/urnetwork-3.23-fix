# 🏷️ v3.23.0-fix.25.12 — Sortable Dashboard Columns

> **TL;DR** Hub dashboard Best Proxies and Proxies tables now support click-to-sort on all columns. No provider changes.

---

## 🏷️ Hub Dashboard

- **Best Proxies** — all columns now sortable client-side: Address, Score, Win%, Traffic, Contracts, Last seen, Status. Click to sort, click again to reverse.
- **Proxies** — column headers are now sortable: Proxy, Traffic, Won, Denied, Win%, Nodes. Sorts the currently loaded data without re-fetching.

---

## ⚠️ Breaking Changes

**None.**

## 📦 Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools hub update
```

> **Note:** This release has no provider changes — `urnet-tools update` is not needed unless you also want the latest provider binary.

```sh
# 🐳 Docker hub (GitHub Container Registry)
docker pull ghcr.io/full-bars/urnetwork-3.23-fix-hub:latest

# 🐳 Docker hub (Docker Hub)
docker pull 3cape/urnetwork-hub:latest
```
