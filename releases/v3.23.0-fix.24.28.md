# v3.23.0-fix.24.28 — 2026-07-01

## Installing / Updating

**Binary (bare metal / VM) — Fresh install:**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.28
```

```sh
docker run -d \
  --name=urfix \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  -e URNETWORK_AUTH_CODE=*** \
  -e HOST_HOSTNAME=$(hostname) \
  -v urfix_config:/root/.urnetwork \
  ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.28
```

## What's New

### Per-Proxy Contract Metrics (PR [#182](https://github.com/full-bars/urnetwork-3.23-fix/pull/182))

Each proxy goroutine now tracks contract acquisition and denial counts with lock-free atomic counters and rolling time windows (15m, 1h, 24h), giving operators real-time visibility into which proxies are winning traffic. Two new visibility layers:

**Provider CLI** — `urnet-tools proxy summary` now includes a Contract Stats section:

```
--- Contract Stats ---
  Acquired:           262
  Denied:             1012
  Win rate:           20.5%
  15m:  42 acquired / 181 denied
  1h:   262 acquired / 1012 denied
  24h:  262 acquired / 1012 denied
```

**Hub dashboard** — Six additions:
- **Contract Win Rate summary card** — fleet-wide acquired vs denied totals and win percentage
- **Contracts/hr uPlot chart** — green (acquired) / red (denied) line chart in the chart row
- **Contracts column** in the fleet node table — sortable, shows per-node raw acquired count
- **Won/Lost columns** in the per-proxy drawer — lets you sort all proxies by contract wins or losses
- **SQLite persistence** — `node_hourly.contracts_acquired` / `contracts_denied` stored with 1-year retention
- **Historical queries** — available via `/api/history?node=<id>&hours=168`

The existing `ContractStatus` callback system in `transfer_contract_manager.go` is now wired to per-proxy counters via `AddContractStatusCallback`, closed over each proxy's index in the `provideWithProxy` goroutine. Data flows through the existing 5-minute bandwidth report to the hub.
