# v3.23.0-fix.24.18 — 2026-06-26

## What's New

### Multi-tier degraded proxy removal

`proxy remove-dead` previously only handled `dead` (never authed) and `inactive` (offline 7+ days). The `degraded` category — proxies that authed once but are now offline — was a blind spot. These zombie proxies clogged the pool with no way to clean them up.

Now `proxy remove-dead` supports:

| Flag | Description |
|---|---|
| `--degraded[=<duration>]` | Remove degraded proxies offline past threshold (default 24h) |
| `--source=<url\|file\|internal>` | Filter by proxy source |
| `--yes` | Skip confirmation for scripting |
| `--preview` | Dry-run, show what would be removed |

Examples:
```
proxy remove-dead --preview
proxy remove-dead --degraded=1h --source=url --yes
proxy remove-dead --degraded --source=file --preview
```

The existing health tiers are all recognized: `dead` → `recently_offline` → `offline` → `long_offline` → `inactive`.

### Proxy activity dashboard

`proxy activity` opens a real-time terminal dashboard showing which proxies are currently carrying client traffic, with per-proxy bandwidth rates, client counts, session age, and recent contract acquisition events. The view refreshes every second. Press `q` or Ctrl+C to exit.

For scripting or pipes, redirecting stdin (`proxy activity -` or `echo | proxy activity`) takes a single snapshot instead of opening the interactive view.
