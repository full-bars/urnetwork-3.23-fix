## Installing / Updating

**Binary (bare metal / VM):**
```sh
urnet-tools update
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.24.2
```

## What's Fixed
- **Rate-limited `[c]ping` log spam**: With ControlPingTimeout=30s and thousands of connections, `[c]ping` was producing ~33 lines/second. Now suppressed to one line per 5 minutes with a suppressed count: `[c]ping (14723 suppressed)`.

**Full Changelog**: https://github.com/full-bars/urnetwork-3.23-fix/compare/v3.23.0-fix.24.1...v3.23.0-fix.24.2
