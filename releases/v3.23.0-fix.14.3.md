## Graceful ZRAM Handling for Unsupported Kernels

Fixes optimize command failing completely on systems where the kernel doesn't include zram support (e.g., Oracle Linux UEK).

### Changes

- **Kernel check**: Detects if zram module is available before attempting setup
- **Graceful skip**: ZRAM is skipped with a simple warning message if unsupported
- **Continue optimizing**: Other OS optimizations (sysctl, ulimits, disk tuning) proceed normally even without ZRAM

### Impact

- Systems like Oracle Linux UEK that lack zram in the kernel now complete optimize successfully
- Other performance tuning still applies even without compressed memory
- No more cryptic module loading failures

### For Users

If you see: "Your kernel does not support ZRAM"
- This is normal on some cloud providers (Oracle, etc.)
- The rest of the optimizations will still apply
- No action needed, optimize will continue

### Optional: Enable ZRAM on Ubuntu

If you're on Ubuntu and want zram support, install the Zabbly kernel (community-maintained, includes additional features):

```bash
# 1. Ensure dependencies
sudo apt update && sudo apt install -y wget curl
sudo mkdir -p /etc/apt/keyrings

# 2. Add Zabbly GPG key
sudo wget -O - https://pkgs.zabbly.com/key.asc | sudo tee /etc/apt/keyrings/zabbly.asc

# 3. Add Zabbly repository
sudo sh -c 'cat <<EOF > /etc/apt/sources.list.d/zabbly-kernel-stable.sources
Enabled: yes
Types: deb
URIs: https://pkgs.zabbly.com/kernel/stable
Suites: $(. /etc/os-release && echo ${VERSION_CODENAME})
Components: main
Architectures: arm64
Signed-By: /etc/apt/keyrings/zabbly.asc
EOF'

# 4. Update and install
sudo apt update
sudo apt install -y linux-zabbly
sudo reboot

# 5. After reboot, run optimize again
urnet-tools optimize -f
```
