## What's Fixed

### 🔒 Dual-Format HMAC Contract Verification

The upstream platform is switching contract signing from legacy to standard HMAC format on July 1, 2026. This release supports both formats seamlessly.

**Before July 1:** Contracts use legacy format — verification works normally (fallback not triggered).

**July 1 onwards:** Platform switches to standard format — verification succeeds via fallback, operations continue uninterrupted.

**How it works:**
- Tries legacy format first (~99.9% success pre-cutover)
- Falls back to standard format (July 1+ contracts)
- Zero performance impact
- No configuration needed

**Files:** `transfer_contract_manager.go` (Verify method, 9 lines)

### 📉 Write Error Log Suppression (WebSocket + QUIC)

Fixed write error log flooding in both WebSocket (runH1) and QUIC (runH3) transports. Both now emit at most one log message per minute globally, with suppression count reported.

**Example output:**
```
[ts]-> error = Timeout. (1,847 suppressed)
```

**Files:** `transport.go` (runH3 write path, 7 lines)
