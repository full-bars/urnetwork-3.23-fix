## What Changed

### 🔒 Dual-Format HMAC Contract Verification

The upstream platform is switching contract authentication from legacy format to standard format on July 1, 2026. This release adds support for both formats, ensuring seamless operation through the migration.

**Technical Details:**
- Added fallback HMAC verification logic in contract verification
- Tries legacy format first (backwards compatible with pre-July 1 contracts)
- Falls back to standard format (post-July 1 contracts)
- Zero performance impact — legacy check succeeds ~99% of the time
- No configuration changes needed

**Files Modified:**
- `transfer_contract_manager.go` — Updated `Verify()` method (9 lines)

## FAQ

**Q: Do I need to change any configuration?**  
A: No. This update is transparent. No config changes required.

**Q: Will this update affect my earnings?**  
A: No. Contract verification happens silently in the background. This fix ensures verification continues working after July 1.

**Q: What happens if I don't update?**  
A: After July 1, the platform will sign all contracts with the new standard format. Your provider will reject every contract with "HMAC verification failed" and stop earning immediately.
