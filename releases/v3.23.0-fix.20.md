# v3.23.0-fix.20 — HMAC Platform Cutover + Write Error Suppression

**Release Date:** June 12, 2026  
**⚠️ URGENT:** Deploy before July 1, 2026

---

## Critical Fix: HMAC Contract Verification Format Migration

The upstream platform switches contract signing from legacy to standard HMAC format on July 1, 2026 (no warning will be issued). This release supports both formats, ensuring seamless operation through the migration.

- Tries legacy format first (~99.9% of pre-cutover contracts)
- Falls back to standard format (post-July 1 contracts)
- Zero performance impact
- No configuration needed

**Files:** `transfer_contract_manager.go` (Verify method, 9 lines)

---

## Fix: Write Error Log Suppression (H1 + H3)

Fixed write error log flooding in both WebSocket (runH1) and QUIC (runH3) transports. Both now emit at most one log message per minute globally, with suppression count reported.

**Example output:**
```
[ts]-> error = Timeout. (1,847 suppressed)
```

**Files:** `transport.go` (runH3 write path, 7 lines)

---

## Deployment

**Before June 26, 2026:**
```bash
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.20
docker run ... ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.20
```

**Post-deployment:** Monitor logs for any HMAC verification errors (none expected). Fewer write error logs is expected behavior.

**If verification fails:** Rollback to v3.23.0-fix.19.1 and file an issue with provider logs + timestamp.

---

**After July 1, 2026:** Contracts from the platform will use standard HMAC format. Providers older than v3.23.0-fix.20 will reject all contracts.
