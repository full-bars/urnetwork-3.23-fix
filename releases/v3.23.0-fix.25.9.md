# 🔧 v3.23.0-fix.25.9 — Dash Shell Compatibility

> **TL;DR** Two fixes for `onboard.sh` dash shell compatibility — removed `set -e` and added `|| true` guards on `curl` assignments. No provider or hub changes.

---

## 🐛 Dash Shell Compatibility

**The bug:** `onboard.sh` used `set -e`, which causes dash (the default `/bin/sh` on Debian/Ubuntu) to exit immediately on non-zero returns from `jq` and `python3` — even when those were intentionally handled by `if`/`||` chains. Bash is more forgiving, but the script targets `/bin/sh` and must work with dash.

**The fix:** Removed `set -e` from the onboarding script and added explicit `|| true` guards on `curl` assignments for robust cross-shell (dash/bash) compatibility.
