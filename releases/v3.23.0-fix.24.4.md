## What's Fixed

- **`proxy add-source` held proxy lock during SOCKS5 probe**: Adding a proxy URL source acquired the proxy lock at the start of the function, then held it through the entire SOCKS5 reachability probe (~97s for 1850 entries). Any concurrent `proxy add-source` or `removeDeadProxies` call during that window failed with "could not acquire proxy lock." Now the lock is released immediately after writing the state file, before the probe runs. Multiple concurrent `proxy add-source` calls no longer block each other.
