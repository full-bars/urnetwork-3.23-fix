## What's New

### `urnet-tools -v` now reports the version that's actually running

`urnet-tools -v` read its "Current version" from a `.version` text file that only the installer rewrites. If a binary was ever updated out of band, that file went stale, so `-v` could confidently report an old version while a newer binary was actually running — which recently sent an outage investigation chasing the wrong build for hours.

It now asks the binary itself (`urnetwork --version`) as the source of truth, and **self-heals** the stale file, reporting exactly what it corrected:

```
Current version: v3.23.0-fix.24.6
urnet-tools: Corrected stale version file: v3.23.0-fix.18.1 -> v3.23.0-fix.24.6
```

> [!TIP]
> If `-v` ever showed a version you didn't expect, run it once after upgrading and it will reconcile the file to reality.

### Quieter logs: per-proxy `[traffic]` lines only when serving

The per-proxy `[traffic]` line printed once per proxy per tick for any proxy that moved bytes. Connected-but-idle proxies still emit a few bytes/sec of keepalive, so a full node flooded the log with thousands of lines every tick, burying `[net][s]select`, `[contract]`, and error output.

Per-proxy lines now print **only for proxies actively carrying client sessions** (`clients > 0`). An idle node prints just the rollup:

```
[traffic] total rx=16.8 KB/s tx=19.4 KB/s clients=0 active_proxies=3998 billable_today=0 B earning=no
```

> [!NOTE]
> The `[traffic] total` summary and `[earn]` line are unchanged — every figure is still aggregated over all proxies. Full per-proxy detail remains available on demand via `urnet-tools proxy traffic`.

## Under the Hood

- **Installer is strictly dash-compatible again.** Fixed a real `echo -e` bug that wrote a literal `-e` into the systemd RAMLOGS override under dash, removed the only non-POSIX `local`, and corrected install one-liners that piped to `bash` instead of `sh`.
- **New `dash-compat` CI guard** keeps it that way: it rejects bashisms (`checkbashisms`), parse failures (`dash -n`), shebang drift, and any future `| bash` install instruction across all three installer scripts.
