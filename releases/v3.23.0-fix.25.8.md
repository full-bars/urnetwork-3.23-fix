# 🔧 v3.23.0-fix.25.8 — Onboard Fix + Hash Routing

> **TL;DR** Hash-based URL routing for the hub dashboard (bookmarkable sections). Onboard script fixes: HTTP fallback double-port bug and direct `/api/cert` fallback. No provider behavior changes.

---

## 🌐 Dashboard

- **Hash-based URL routing** — each section now has a distinct URL: `#overview`, `#servers`, `#proxies`, `#contracts`, `#best`. Bookmarkable and sharable.
- **Live-tail query uses `INDEXED BY idx_pnh_hour_proxy`** — SQLite was picking the wrong single-column index for "all nodes" leaderboard queries. Fixed planner choice.

## 🔧 Onboard Script

- **HTTP fallback double-port bug fixed** — the old URL construction produced `http://host:8443:8080` (two ports).
- **Added `/api/cert` fallback** — if token-based `/api/ca-cert` fails on both HTTPS and HTTP, try direct certificate retrieval.
