## What's New in v3.23.0-fix.18.1

This is a minor patch release that builds on v3.23.0-fix.18 with convenient Docker command aliases.

### Installing / Updating

**Binary (bare metal / VM):**
```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/urnetwork-3.23-fix/refs/heads/main/scripts/Provider_Install_Linux.sh | sh -s -- install
```

**Updating an existing install:**
```sh
urnet-tools update -t v3.23.0-fix.18.1
```

**Docker:**
```sh
docker pull ghcr.io/full-bars/urnetwork-3.23-fix:v3.23.0-fix.18.1
```

---

### Docker Convenience Aliases

For Docker deployments, this release adds command aliases to make monitoring and troubleshooting easier without needing to remember full `docker exec` syntax:

**View live logs (RAMLOGS-aware):**
```sh
docker exec urfix logs
```
Automatically tails `/dev/shm/urnetwork.log` when RAMLOGS is enabled, or falls back to stdout otherwise.

**View proxy traffic report:**
```sh
docker exec urfix proxy-traffic
```
Shows per-proxy bandwidth and active session counts.

These aliases are equivalent to the binary commands `urnet-tools logs` and `urnet-tools proxy traffic`, making the Docker experience more consistent with bare-metal installations.

### Inherited Features

This release includes all features from v3.23.0-fix.18:

- **JWT Smart Refresh & Self-Healing Auth**: Automatic token refresh with recovery from authentication failures
- **Proxy Hot-Reload** (from v3.23.0-fix.17): Add and remove proxies without restarting
- **Proxy Health Monitoring**: `urnet-tools proxy health` or `docker exec urfix proxy-health`
- **Per-Proxy Traffic Tracking**: Bandwidth and active session visibility
