## Highlights

### 🛡️ Deep Packet Inspection — Layered Security Pipeline (PR #160)

The old `ip_security.go` was a 66,000-line monolith with a port-based blocklist. It's been replaced with a layered DPI pipeline that actually inspects L7 payload:

**Layer 1 — CFAA Static Reputation:** Blocked IP ranges (binary-search packed table, zero allocation) + port/protocol policy. Three-way verdict: drop / allow / pass-to-DPI. IPv6 blocked subnets now supported (214 ranges from Spamhaus DROPv6).

**Layer 2 — DMCA Stateful Detection:** Per-flow state machine that inspects the first 8 packets. Detects BitTorrent from plaintext signatures (BEP 3 peer wire, BEP 3 HTTP tracker, BEP 5 DHT KRPC, BEP 15 UDP tracker, BEP 29 uTP). Falls back to an entropy heuristic for obfuscated/encrypted non-web flows.

**Web Standard Exemption:** TLS/DTLS/QUIC/STUN byte signatures exempt legitimate encrypted flows from the entropy heuristic — no false positives on HTTPS.
