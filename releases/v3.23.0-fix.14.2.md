## Update Command Reliability Fix

Fixes silent update failures on systems missing `jq` or `python3`.

### Changes

- **Clear error messaging**: Update now fails loudly with helpful instructions if JSON parsing tools are missing
- **Validation**: Date parsing is validated before numeric comparison to prevent cryptic '[: Illegal number' errors
- **User guidance**: Error message directs users to install missing dependencies

### Issue

Previously, systems without `jq` and `python3` would silently report 'up-to-date' even when updates were available. The '[: Illegal number' error in logs was confusing and didn't indicate the root cause.

### Action Required

If you got 'up-to-date' but know there's a newer version:
```bash
sudo apt-get install -y jq python3
urnet-tools update
```
