# 🔒 v3.23.0-fix.25.13 — Best Proxies Live Scan + Crypto Bump

> **TL;DR** Best Proxies "Last seen" column now shows today-accurate timestamps via live `proxy_node_hourly` scan. Dependency bump on `golang.org/x/crypto` resolves 7 critical CVEs. No provider behavior changes.

Best Proxies "Last seen" column now UNIONs a live scan of `proxy_node_hourly` alongside `proxy_fleet_daily`, so proxies active today show "today" instead of "1d ago" (the `fleet_daily` rollup has a ~26h lag).
