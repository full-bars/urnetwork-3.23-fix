## 🗂️ What's New

> [!NOTE]
> **Deferred Features:** Porting of upstream's *gopacket removal* (PR #263) and *memory budget enforcement* (PR #264) have been temporarily deferred from this release. Deep-dive code reviews revealed several critical regressions and memory bounds issues in the upstream implementations that previous reviews failed to catch. These will be merged in a future release once they meet our stability standards.

### 🧠 Core Networking Stability

**Hot-Reload Lock Race & Shutdown Diagnostics** — PR #260
Fixed a race condition during hot-reloads by ensuring idempotent lock releases. Additionally added cancel-time stack trace diagnostics during provider shutdown for easier debugging of exit hangs.

**Core Stability & Leak Cleanup** — PR #266
Patched a series of structural edge cases: fixed memory leaks in the transfer pool and route manager (unbound map growth), resolved a panic risk in WebRTC stream ID parsing, prevented an infinite CPU spin loop during warmup on small node clusters, and gracefully handled auth context cancellations.

### ⚡ Upstream Synchronization

**Upstream New Infrastructure Files** — PR #261
Ported upstream infrastructure commits (`ee7a476` + `83dc999`). This introduces extensive foundational components for future features, including Egress interfaces, Memory Budgets, Contract Stats, Peer Management, and `ip_assoc.go`. Also includes fixes for peer manager state notifications and disconnect memory bounds.

**Peer API Refactor & Pause Fix** — PR #262
Ported upstream's updated Peer API, featuring the critical `ReceiveFunction` type change and the pause behavior fix.

**Upstream 532ee20c Fixes** — PR #265
Successfully ported upstream's `532ee20c` patchset, which includes critical fixes for mode election, hot-spin CPU utilization, and connection eviction, alongside the new `MonitorValue` constructs.

### 🛠️ CI/CD & Operations

**Go 1.26 Toolchain & Dependencies** — PR #267
Bumped the underlying compiler from `1.25.x` to `1.26.4`. Additionally bumped core dependencies including `pion/webrtc` (v4.2.15), `quic-go` (v0.60.0), and `golang.org/x/*` libraries.

**Official `dl.fullbars.xyz` URLs** — PR #258
Updated all installation scripts and documentation to point to the new, shortened `dl.fullbars.xyz` domain for cleaner curl commands.

**Docker: In-Place Updates** — PR #255
Added the `urnet-tools update` command inside the Docker container, allowing for in-place binary replacements without needing to pull a completely new container image. 

**Standardized Repository Templates** — PRs #268, #269
Added structured GitHub templates for Pull Requests and Releases to enforce high-signal, technical documentation across the repository.
