# Setup Guides

Choose the guide that matches your experience level.

## [🐣 Beginner — 5-Minute Quick Start](beginner.md)
I just want to run a provider. Give me the shortest path from zero to providing, no jargon.

**Time:** ~5 minutes
**What you'll do:** Copy three commands, enter your auth code, done.

## [🧭 Intermediate — Custom Setup](intermediate.md)
I want to understand what I'm setting up, choose between Docker and systemd, add my own proxies, and check that everything is healthy.

**Time:** ~15 minutes
**What you'll do:** Pick your install method, configure proxies, learn the basic commands.

## [🚀 Advanced — Production Fleet](advanced.md)
I'm running multiple servers, tuning performance, setting up the hub dashboard, and need to know what to do when things go wrong.

**Time:** varies
**What you'll learn:** Performance profiles, fleet management, hot-reload, hub setup, troubleshooting.

---

> 🧠 **Not sure where to start?** If you just want to try it out, start with the Beginner guide. If you're setting up a server you plan to rely on, start with Intermediate. If you already run nodes and want to optimize a fleet, go straight to Advanced.
